Traduction anglaise des questions

Le statut de traduction est indépendant de la publication. Dans le jeu, seules les traductions validées sont montrées (réglage modifiable dans « Réglages du jeu ») ; sinon la question reste en français. L'arabe n'est montré qu'en Religion ; il reste conservé en base pour les autres thèmes.

1. Importer un fichier de traductions

Format « kounouzi-traductions » (JSON). L'import se fait en deux temps : simulation (rien n'est écrit, rapport détaillé), puis import par lots. Seul l'anglais est écrit ; le français, l'arabe et les références ne sont jamais modifiés. Les lignes importées passent « à relire ». Un import interrompu se relance simplement : les lignes déjà importées sont reconnues.

2. Exporter les questions à traduire

Produit un fichier au même format, avec le français rempli et l'anglais vide, prêt à être traduit puis réimporté.
